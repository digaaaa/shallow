# Shallow

Shallow helps people practice face-to-face interaction through two features:

- **Challenges**: small real-world social tasks (e.g. "talk to a stranger today") at easy, medium and hard levels, with a daily streak for completed challenges.
- **Prompts**: conversation starters to use with friends, grouped by category, picked at random without repeating ones already used.

This is a single-process monolithic app using SQLite for storage, built for Individual Assignment 1. The two features are kept logically separate so they can be split into services later.
